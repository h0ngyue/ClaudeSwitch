# ClaudeSwitch

[English](README.en.md) | 中文

一个 macOS 菜单栏小工具：**在 Claude Desktop 里一键切换多个 Claude 订阅账号，并把 Code 会话带到新账号上接着用。**

## 解决什么问题

如果你有好几个 Claude Pro / Max 账号，平时在 Claude Desktop 里干活，大概会遇到这些麻烦：

- **换号很麻烦。** Desktop 一次只能登录一个账号，换号要先退出登录，再输邮箱、收验证码。
- **换号后会话不见了。** Code 页的会话列表是按账号分开存的。一个号额度用完、任务被打断，换到另一个号后左侧列表里找不到原来的会话，没法接着干。
- **不知道哪个号还有额度。** 只能一个个登进去看。

ClaudeSwitch 把这三件事放进一个菜单栏面板：

- **额度一览**：每个账号的 5 小时额度、每周额度还剩多少，什么时候重置，下次什么时候扣费。布局和 Desktop 设置页一样。两种额度下面各有一条细灰条表示这个窗口还剩多少时间，鼠标悬停可看用量比时间快还是慢。
- **一键切换**：每个账号只要在工具里登录一次，之后切换不用再收验证码。
- **会话跟着走**：面板里列出所有账号的近期会话。勾选要带过去的会话，点「切换并同步」，**Desktop 只重启一次**，新账号的列表里就有这些会话，点进去接着跑。
- **随时能撤销**：同步可以撤销，目录改动可以一键还原，详见 [回退手册](回退手册.md)。

## 安装

需要 macOS 14 或更新版本，装好 Claude Desktop 和 Xcode Command Line Tools（提供 `swift` 和 `python3`，没装的话运行 `xcode-select --install`）。

```bash
git clone https://github.com/h0ngyue/ClaudeSwitch.git
```

```bash
cd ClaudeSwitch && scripts/build_app.sh
```

```bash
open build/ClaudeSwitch.app
```

打包好的 `build/ClaudeSwitch.app` 可以拖进「应用程序」。菜单栏会出现一个双人图标，旁边显示当前账号的 5 小时额度剩余百分比。

第一次点刷新时，macOS 会问是否允许 `security` 读取钥匙串里的「Claude Safe Storage」，点「始终允许」。原因见下面的「原理」。

## 怎么用

1. **添加账号**：点面板里的「添加账号」，按弹窗步骤走。工具会退出 Desktop（第一次使用时先备份数据目录），保存当前账号，然后打开一个空白的 Desktop 登录页。你在里面登录另一个账号，工具会自动识别并保存。**每个账号只需要做一次。**
2. **切换账号**：点目标账号的「切换」→ 在「近期会话」里勾选要带过去的会话 → 点底部的「切换并同步 N 个会话」。一个都不勾也可以，就是单纯换号。
3. **不换号，只把别的号的会话拿过来**：在近期会话里勾选，点「同步选中到当前账号」，再点「重启 Desktop」。
4. **看额度**：点每个账号右上角的刷新按钮。进度条显示剩余额度（50% 以上绿、20%~50% 橙、20% 以下红）。重置倒计时会每分钟在本地自动更新，不用联网；切换账号后会自动刷新一次新账号。

> 切换和添加账号都会退出 Desktop，正在运行的 Code 会话会被中断。先等手上的任务告一段落。

## 同步会话前必看：Token 消耗

**同步过去的会话，在新账号里第一次继续时，Claude 会把整段历史对话重新读一遍。**

- 对话记录本身是所有账号共用的，所以新账号能看到完整上下文。
- 但是**提示缓存不跨账号**。在原账号里，每轮对话的大部分历史都会命中缓存，很便宜；换到新账号后，第一条消息要把全部历史当作新输入，全价计费。
- 举个例子：一个已经积累了 15 万 token 的长会话，在新账号上发第一句「继续」，光读历史就是 15 万 token 输入，能明显吃掉新账号一截 5 小时额度。
- 读过一次之后，新账号这边会重新建立缓存，后面每轮的消耗回到正常水平。

省 Token 的做法：

1. **只同步真要接着干的会话**，不要全选。工具默认只勾选被额度打断的会话。
2. **旧账号还有额度时，先 `/compact` 再切换。** 压缩后的会话很短，在新账号上读一遍便宜得多。
3. **旧账号已经没额度了**：在新账号里打开会话，第一条消息就发 `/compact`，不要先发「继续」。压缩也要读一遍历史，但只读这一次，之后每轮都很便宜。
4. **特别长、或者已经跑偏的会话**，干脆别同步：让 AI（或者你自己）写一份交接摘要，在新账号开一个新会话。
5. **不要在两个账号上同时跑同一个会话。** 它们写的是同一份对话记录，可能互相覆盖。

## 原理

- **切换**：Desktop 只认 `~/Library/Application Support/Claude/` 这一个数据目录。工具把每个账号的目录分别保存起来，切换时退出 Desktop、交换目录、再打开 Desktop。所以每个账号只需登录一次。
- **会话同步**：Code 会话列表其实是 `claude-code-sessions/<账户ID>/<组织ID>/` 下面一个个几 KB 的索引文件，真正的对话记录在 `~/.claude/projects/`，所有账号共用。同步只是把索引文件复制到目标账号的目录，对话记录不复制、也不修改。
- **省空间**：会话索引目录和 Desktop 的运行时（约 10G）放进共享区，各账号目录用软链指过去，不会每个账号存一份。
- **额度**：Desktop 的登录 cookie 是加密存储的，密钥在钥匙串的「Claude Safe Storage」里。工具读这个密钥，解密对应账号的 cookie，然后请求 claude.ai 的用量接口，也就是 Desktop 设置页自己用的那个。密钥和 cookie 只在内存里用，不写盘、不打印，只发往 claude.ai。

## 风险与须知

- **这是非官方工具**，与 Anthropic 无关。用到的 claude.ai 接口没有公开文档，随时可能变；Desktop 改了数据目录结构，工具也可能失效。
- **多账号是否符合服务条款，请自行判断，风险自负。** 工具尽量少发请求：不定时轮询，只在你点某个账号的刷新按钮、或刚切换到某个账号时请求那一个账号，平时一次刷新只发 1 个请求，请求头和 Desktop 一致。
- **不删数据。** 脚本只做改名、移动和建软链。第一次添加账号前会备份数据目录（不含 10G 运行时）。
- 界面目前只有中文。

## 数据放在哪

工具自己的数据都在 `~/Library/Application Support/ClaudeSwitch/`：

| 位置 | 内容 |
|---|---|
| `profiles/` | 当前没在用的账号的数据目录 |
| `shared/` | 各账号共用的会话索引和 Desktop 运行时 |
| `backup/` | 第一次添加账号前的备份 |
| `state/` | 记录当前是哪个账号 |
| `settings.json` | 你起的名字、识别到的邮箱 |
| `usage_cache.json` | 上次查到的额度（不含 cookie） |
| `actions.log` | 每次操作的日志 |

## 和 cc-switch 这类工具有什么不同

cc-switch 这类工具切换的是 Claude Code 命令行用的 API 供应商或令牌，管不到 Desktop 的登录状态。ClaudeSwitch 只做一件事：切换 Claude Desktop 本身登录的账号，并把会话带过去。
